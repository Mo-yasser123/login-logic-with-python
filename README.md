# 🔐 Simple Python Login & Registration Logic v1.0

A straightforward, console-based Python script that demonstrates user registration and authentication logic using interactive inputs and validation loops.

---

## 📌 Features

- **User Registration:** Prompts the user to create a username and password.
- **Login Validation:** Asks for login credentials and continuously checks them against the registered data.
- **Retry Mechanism:** Uses a `while` loop to repeatedly prompt the user until correct credentials are entered.
- **Success Feedback:** Displays a confirmation message upon successful authentication.

* **Language:** Python 3.x
